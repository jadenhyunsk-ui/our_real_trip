# 여행 전체 관리 프로그램

## 여는 방법
`index.html`을 브라우저에서 열면 됩니다.
스타일·기능이 모두 HTML 안에 들어 있어 외부 파일 없이 단독 실행됩니다.
GitHub에 올려두면 링크 하나로 가족 모두가 열 수 있습니다 (아래 **GitHub로 배포하기** 참고).

**⚠️ 모바일 · 구글 드라이브 앱 주의사항** (로컬 파일로 쓸 때만 해당)
구글 드라이브 앱에서 `index.html`을 **탭해서 바로 열면 안 됩니다.** 드라이브 앱의 자체 미리보기 화면은 자바스크립트를 실행하지 않아서 화면이 텅 비어 보입니다(상단 파란 줄만 보임).
반드시 아래처럼 여세요:
1. 드라이브 앱에서 파일을 탭하지 말고, 파일 옆 **⋮(더보기)** 버튼을 누른다.
2. **"다른 앱으로 열기"**(공유 → 앱 선택)를 눌러 **크롬**(또는 삼성 인터넷 등 실제 브라우저)을 선택한다.
3. 매번 반복하기 번거로우면, 크롬으로 연 뒤 브라우저 메뉴 → **"홈 화면에 추가"** 로 아이콘을 만들어두면 이후엔 바로 열린다.

GitHub Pages로 배포하면 이 문제 자체가 없습니다 — 그냥 일반 웹사이트 링크라 어떤 앱에서 눌러도 브라우저로 열립니다.

```
   └─ 이미지/                          첨부 이미지 보관 (개인 데이터, 저장소에는 올라가지 않음)
```

## GitHub로 배포하기 (jadenhyunsk-ui/Our_real_trip 기준)
자녀일정관리 프로젝트와 같은 방식으로, GitHub Pages에 올려서 링크로 접속하는 정적 웹사이트로 씁니다.

### 처음 한 번만: 저장소 만들고 올리기
1. https://github.com/new 에서 저장소 생성
   - Owner: `jadenhyunsk-ui`
   - Repository name: `Our_real_trip`
   - **Public**으로 생성 (GitHub Pages 무료 사용 조건. 아래 "공개 저장소 관련 주의" 참고)
   - README 등 아무것도 체크하지 않고 바로 **Create repository**
2. 이 폴더(`trip-manager`)에서 터미널을 열고 아래 명령 실행 (이미 `git init`은 되어 있는 상태입니다):
   ```
   git add -A
   git commit -m "여행 관리 앱 초기 배포"
   git branch -M main
   git remote add origin https://github.com/jadenhyunsk-ui/Our_real_trip.git
   git push -u origin main
   ```
   (Git 처음 사용이면 로그인 창이 뜨면 GitHub 계정으로 로그인하세요. 브라우저 로그인 창이 안 뜨면 GitHub Desktop을 설치해서 같은 폴더를 열어 커밋·푸시해도 됩니다.)
3. GitHub 저장소 페이지 → **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** / **/(root)** 선택 → **Save**
   - 1~2분 뒤 페이지 상단에 `https://jadenhyunsk-ui.github.io/Our_real_trip/` 링크가 뜨면 완료
4. 그 링크를 가족 카톡방 등에 공유하면, 다들 그 링크만 누르면 바로 앱이 열립니다 (index.html이라 폴더 링크만 눌러도 자동으로 열림).

### 그 다음부터: 코드 수정할 때마다
```
git add -A
git commit -m "수정 내용 설명"
git push
```
푸시하고 1분 정도 지나면 실제 사이트에도 반영됩니다.

### 문제 해결: 비교 페이지(항공/호텔/투어/렌트카 비교)가 안 열려요
GitHub 웹사이트의 **"Add file → Upload files"** 로 `index.html`만 직접 끌어다 올리면 `DATA` 폴더는 함께 올라가지 않습니다. `DATA/pages/*.html`(비교 페이지)이 저장소에 없으면 그 링크는 전부 404가 됩니다.
**해결**: 반드시 위 "처음 한 번만" 단계의 `git push`로 폴더 전체를 올리세요. 이미 웹 업로드로 `index.html`만 올려둔 상태라면:
```
git push -u origin main --force
```
저장소에 이미 있는 건 이 프로젝트 초기 웹 업로드 몇 개뿐이라 덮어써도 안전합니다. (다른 사람과 같이 쓰는 저장소이거나 지키고 싶은 커밋이 있다면 `--force` 대신 `git pull origin main --allow-unrelated-histories` 로 병합하세요.)
푸시 후 GitHub 저장소 페이지에서 `DATA` 폴더가 보이는지 확인하세요.

### 공개 저장소 관련 주의
- GitHub Pages 무료 버전은 **공개(Public) 저장소**만 지원합니다. 이 저장소를 public으로 만들면 코드(HTML/JS)는 누구나 볼 수 있지만, **실제 여행 데이터는 코드에 들어있지 않고 Firebase에 별도 저장**되므로 코드 자체가 공개되어도 여행 일정이 노출되지는 않습니다.
- 다만 Firebase 설정(`firebaseConfig`)이 코드에 그대로 들어있고, 아래 "Firebase 데이터베이스 보안 규칙"처럼 `/trip` 경로가 누구나 읽고 쓸 수 있게 열려 있습니다. **주소(`https://jadenhyunsk-ui.github.io/Our_real_trip/`)를 아는 사람만 실질적으로 접근한다는 전제**의 가벼운 보안 수준입니다 — 링크를 불특정 다수에게 공개하지 않는 한 지금 수준으로 충분합니다. 더 엄격하게 하려면 Firebase 익명 로그인을 추가하거나, Realtime Database 규칙에 비밀 토큰 검사를 추가할 수 있습니다.
- `DATA/json/*.json`, `DATA/trip-data-*.json`, `DATA/이미지/*` 는 `.gitignore`에 이미 등록되어 있어 실수로 올라가지 않습니다. (개인 백업 JSON·사진은 로컬에만 보관하세요.)
- 정말 비공개로 하고 싶다면 GitHub Pro/Team 요금제에서 **Private 저장소 + Pages**를 쓸 수 있습니다.

## 항공 · 호텔 · 투어 · 렌트카 비교
각 탭(2/3/4/6번) 아래 **[비교하기]** 버튼을 누르면 해당 비교표로 이동합니다. 비교표는 **원래 탭과 동일한 엑셀 표 형식**이며, 맨 왼쪽 **선정** 열에 체크박스가 있습니다.

- **📥 현재 OO 탭 값 불러오기** 버튼: 이미 원래 탭(항공/호텔/투어/렌트카)에 입력해둔 값이 있으면, 이 버튼으로 비교표에 그대로 불러와 **선정 체크까지 자동으로** 됩니다. 이미 불러온 항목은 다시 눌러도 중복 추가되지 않습니다. 여기에 다른 후보를 몇 개 더 추가해서 나란히 비교한 뒤 다시 선정할 수 있습니다.
- 체크한 뒤 맨 아래 **[✅ 반영]** 버튼을 누르면, 체크된 행만 원래 탭에 실제 값으로 입력됩니다. **불러오기로 가져온 항목**은 반영해도 새 줄이 추가되지 않고 **원래 있던 그 줄을 덮어씁니다** (직접 새로 추가한 후보만 새 줄로 들어갑니다).
- 항공 비교: 표 안에서 여정·구간(날짜/시간/항공사/편명/출발지/도착지)까지 그대로 채우면, 선정 시 항공 탭에 그 여정 그대로 추가/갱신됩니다.
- 호텔 비교: 행마다 **체크인 / 체크아웃** 날짜를 지정하면, 선정 시 그 기간(체크아웃 전날 밤까지)의 호텔 탭 각 날짜 칸이 채워집니다. 둘 다 비워두면 전체 여행 기간에 적용되고, 지정했는데 여행 기간과 안 겹치면 그 후보는 건너뛰고 알려줍니다(전체 기간으로 덮어쓰지 않습니다).
- 투어 비교: **카테고리** 칸 옆에 **날짜** 칸이 있어 후보 투어의 예정일을 바로 적을 수 있고, 선정 시 투어 탭의 날짜로 반영됩니다. **운영사/대행사** 오른쪽에는 **투어가격**(금액 + 통화) 칸이 있습니다. 선정 시 이름·운영사·가격·비고가 투어 탭에 그대로 추가/갱신됩니다.
- 투어 비교표는 같은 **카테고리**를 입력하면 같은 옅은 색으로 묶여 표시되고, 카테고리가 바뀌는 경계마다 살짝 여백이 생겨 구분됩니다.
- 렌트카 비교: 대여기간 / 대여시간 / 이름 / 픽업·드랍 / 대여기간·조건 / 차종 / 가격(자유 텍스트) / 장점 / 단점 / 보험 보장 범위 / 평가 메모 칸으로 비교합니다. 선정 시 이름·차종·보험·메모가 렌트카 탭에 추가/갱신되고, **가격** 칸에서 숫자·통화를 알아볼 수 있으면 렌트카 탭의 금액 칸도 함께 채워집니다. 날짜는 직접 채워주세요.
- 비교표의 각 입력 칸(장점/단점/비고 등)은 처음부터 입력된 글자가 다 보이도록 높이가 자동으로 맞춰지고, 이후에도 칸 오른쪽 아래를 끌어서 원하는 만큼 세로로 더 늘리거나 줄일 수 있습니다.

## 금액 · 통화
- 각 탭 위 **설정 바**에서 여행지를 입력하면 현지 통화가 자동 선택됩니다.
  (호주→AUD, 일본→JPY, 베트남→VND, 태국→THB, 유럽→EUR 등 22개 통화)
- **여행지 · 시작일 · 종료일**이 한 줄에 나란히 배치되어 모바일 화면에서도 바로 한눈에 들어옵니다.
- 통화는 풀다운에서 직접 바꿀 수도 있고, **환율(1현지통화=원)** 도 수정할 수 있습니다.
- **현지 통화 옆 + 버튼**으로 추가 통화를 최대 **2개**까지 더 등록할 수 있습니다. 추가하면 그 통화의 환율 입력칸도 함께 생기고, 앱 전체의 금액 칸 풀다운(✕ 버튼으로 삭제 가능)에 반영됩니다.
- 모든 금액 칸은 기본 현지 통화로 입력되며, 칸 오른쪽 작은 풀다운에서 **현지 통화 / 추가 통화 / KRW** 중 선택할 수 있습니다. 숫자를 입력하면 **천단위 콤마(1,234,567)**가 자동으로 붙고, 8자리 숫자까지 넉넉히 보이도록 폭이 맞춰져 있습니다.
- 합계는 항상 원화로 환산되고, 아래에 입력 원본(사용한 통화별 금액)이 함께 표시됩니다.
- **SUMMARY 탭의 사용금액**은 항공·호텔·투어·지출노트·렌트카 5개 탭의 금액을 자동으로 합산합니다. 지출노트에서 "가져오기"로 불러온 항목은 원본 탭에서 이미 집계되므로 중복으로 더하지 않습니다.
- 항공/호텔/투어/렌트카는 지출노트와 마찬가지로 실제 이용 날짜와 상관없이 항상 **출발전** 금액으로 집계됩니다(보통 출발 전에 미리 결제하므로). 날짜별 사용금액 칸에는 직접 입력한 지출노트 항목만 표시됩니다.
- **호텔은 체크인~체크아웃 한 건을 하나의 금액으로 계산**합니다. 여러 밤이 한 줄로 묶여 표시돼도(숙박 기간 내 매일 같은 금액이 내부적으로 저장되어 있음) 합계·가져오기에서는 항상 그 숙박 전체를 1건으로만 계산해 밤 수만큼 중복으로 더해지지 않습니다.
- 설정 바 우측 상단의 **토글 스위치**로 여행지/통화/환율/기간 입력칸을 접었다 펼 수 있습니다. 접으면 요약 정보(여행지·통화·기간)만 한 줄로 남습니다.

## 지출노트 가져오기
- 지출노트 위 **[📥 항공·호텔·렌트카·투어 값 가져오기]** 버튼을 누르면 그 4개 탭에 입력된 금액을 지출노트로 복사해옵니다.
- 항공·호텔·투어·렌트카는 보통 출발 전에 미리 결제하므로(실제 이용일과 지출일이 다름), 실제 이용 날짜와 상관없이 항상 **출발전**으로 분류됩니다.
- 이미 가져온 항목은 다시 눌러도 중복으로 추가되지 않고, 반대로 **원본 탭에서 그 항목을 지웠다면** 다음에 가져오기를 누를 때 지출노트의 해당 항목도 함께 삭제됩니다.
- 가져온 항목은 SUMMARY의 사용금액 합계에서 제외됩니다(원본 탭 금액으로 이미 집계되어 있으므로).
- 지출노트를 열면 **오늘 날짜** 탭이 자동으로 선택됩니다. 오늘이 여행 기간보다 이전이면 **출발전** 탭이 선택됩니다.

## 화면 형태
모든 탭(비교표 포함)이 **엑셀 표 형태**입니다. 한 행이 한 건이고, 셀을 바로 눌러 수정합니다.
표는 좌우로 밀어서 나머지 열을 볼 수 있습니다.

| 탭 | 열 구성 |
|---|---|
| 0. SUMMARY | 일정(날짜) / 요약 / 호텔 / 이동 / 사용금액 / 비고. **일정 날짜**를 탭하거나 **요약** 칸을 더블탭하면 일정 탭의 그 날짜로 바로 이동합니다. 맨 아래에는 **출발전** 행이 따로 있어 여행 기간 밖에서 쓴 돈을 모아 보여줍니다 |
| 1. 일정 | 일정 / 시간 / 내용 / 메모. 내용 칸은 엔터로 줄바꿈이 가능합니다. 블록 위·아래 손잡이(⋮⋮)를 각각 드래그하면 시작 시각 · 종료 시각을 따로 조절할 수 있습니다. 탭을 열면 타임테이블이 **오전 6시**부터 보이도록 자동으로 스크롤됩니다 |
| 2. 항공 | 여정(왕복/편도)별 구간 행. 가는편·오는편 구간마다 날짜/시간/항공사/편명/출발지/도착지, 여정당 예약처·금액·결제·비고는 한 번만 입력. 경유는 [+ 구간 추가] |

## 저장 · 실시간 동기화
- **Firebase 실시간 데이터베이스**로 가족 모두가 동시에 입력해도 서로의 내용이 몇 초 안에 자동으로 반영됩니다 (구글시트처럼 동작).
- 입력하면 즉시 이 기기에도 저장되고(화면 아래 "저장됨 ✓"), 잠시 후 다른 가족 화면에도 자동 반영됩니다.
- 상단 상태 표시로 연결 상태를 확인할 수 있습니다: 🟢 Connected / 🟡 Connecting… / 🔴 Disconnected(새로고침 필요).
- 인터넷 연결이 반드시 필요합니다 (오프라인일 땐 이 기기에만 임시 저장되고, 다시 연결되면 자동으로 동기화됩니다).
- [⬇ 내보내기] / [⬆ 가져오기]는 백업/복원용으로 남아 있습니다 (오프라인 보관, 사고 시 복구 등).
- [🟩 엑셀 아이콘]을 누르면 현재 여행 데이터를 **진짜 .xlsx 파일**로 내려받습니다. 항공·호텔·투어·지출노트·렌트카가 각각 별도 **시트**로 나뉘고, 헤더 색상·금액 강조 등 앱 화면과 비슷한 스타일이 적용됩니다.

### Firebase 데이터베이스 보안 규칙
Firebase 콘솔 → Realtime Database → 규칙 탭에서 아래처럼 설정해 `/trip` 경로만 열어두는 걸 권장합니다 (테스트 모드는 시간이 지나면 자동으로 잠깁니다):
```json
{
  "rules": {
    "trip": {
      ".read": true,
      ".write": true
    },
    "$other": {
      ".read": false,
      ".write": false
    }
  }
}
```
가족만 아는 링크/설정값이라 이 정도로 충분하지만, 더 엄격하게 하려면 Firebase 익명 로그인을 추가로 붙일 수 있습니다.
